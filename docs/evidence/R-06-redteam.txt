# R-06 red-team evidence, 2026-11-17

Replayed 65 tool calls through guard.sh and 36 texts through inject-scan.sh (scripts/redteam/*.tsv); nothing is executed.
The cases were chosen to probe the limits of text matching, so the score is a list of known gaps, not a detection rate.
MISS = the hook let through something it should stop. FALSE-POS = it stopped something legitimate.

Fixes so far (the first two are already on main, the last one is new in this change):
- the download-into-a-shell rule needs a word boundary after sh, so a pipe into sha256sum or shasum no longer matches;
- the force push rule needs git push and a standalone -f/--force in the same command (no ; & | between them).
  Cases f09 and f10 are the two commands it wrongly blocked during this stage.
- the destroy rule needs destroy as a word in the same command as terraform; case f11 is the plan filter it blocked.
